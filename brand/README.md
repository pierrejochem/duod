# duod brand package

| File | Use |
|---|---|
| `brand-guidelines.md` | Identity, colors, type, voice, logo rules |
| `messaging.md` | Positioning, taglines, boilerplate, launch copy |
| `social/github-social-preview.png` | 1280x640. Upload in GitHub: Settings → Social preview |
| `social/og-image.png` | 1200x630. Used by the docs site (`og:image`, `twitter:image`) |
| `social/square.png` | 1080x1080. Instagram, LinkedIn, Mastodon cards |
| `social/*.html` | Editable sources. Re-render with `make brand` |

Logos live in `../assets/` (`duod-logo.svg`, `duod-logo-dark.svg`, `duod-mark.svg`, `duod-wordmark.svg`, `favicon.svg`).
