Getting started: the five-minute demo

The demo starts a private registry (Portus), Traefik, duod, three demo services and a live dashboard with one command. Use it to see blue/green rollouts before you install duod on a real host.

Requirements

You need Docker with Compose v2, git, openssl and curl. You do not need Go, because duod is built inside Docker.

Start the demo

Clone the repository and run:

make demo-up      # registry, Traefik, duod, 3 services, dashboard
make demo-open    # dashboard, shop and Portus in your browser

The dashboard is at http://dashboard.localhost. Run make help for every target.

Roll out a new version

cd demo
./demo.sh release shop 1.1.0

The script builds the image, pushes it to the registry and bumps the tag in the demo GitOps repo. duod picks up the commit. On the dashboard you see the idle slot start, pass its health check, wait for promotion and then take the traffic.

See a broken release rejected

./demo.sh release api 1.1.0 --broken

The new version fails its health check in the preview slot. The old slot keeps serving, so users see no error. The app shows phase Degraded until you push a fix or run duod retry api.

Promote, abort and roll back

Services with autoPromotionEnabled: false pause after a healthy preview. Use the CLI:

duod promote shop    # switch traffic to the preview
duod abort shop      # discard the paused preview
duod rollback shop   # back to the previous slot

Stop the demo

make demo-down     # stop
make demo-reset    # wipe all demo state

The demo folder also contains a 15-minute presenter run-book. See demo/ on GitHub.
