CLI and REST API

The duod binary is both the operator and its command-line client.

Connect the CLI

export DUOD_SERVER=http://127.0.0.1:9800 DUOD_TOKEN=...

Commands

CommandWhat it does
duod run -config FILE [-log-format text|json]Run the operator. The systemd unit does this.
duod validate -config FILECheck a config and print each app's Traefik file.
duod listAll apps with phase, sync status and revisions.
duod get <app>Phase, sync, active, preview and previous slot.
duod history <app>Event log: RolloutQueued, RolloutStarted, PreviewHealthy, Promoted and more.
duod sync <app>Fetch Git now.
duod promote <app>Paused: switch traffic to the preview.
duod abort <app>Cancel the analysis or discard the paused preview.
duod rollback <app>Back to the previous slot. No Git change needed.
duod retry <app>Clear the failed-revision marker and try again.
duod versionPrint the version.

Example output

$ duod list
APP   PHASE     SYNC       ACTIVE  REVISION  PREVIEW  TARGET    MESSAGE
api   Degraded  OutOfSync  green   578ef707  -        64dc3ce3  revision 64dc3ce3 failed (...); still serving 578ef707 from green
shop  Healthy   Synced     blue    64dc3ce3  -        64dc3ce3  serving 64dc3ce3 from blue

Phases

PhaseMeaning
NewNever deployed.
ProgressingThe preview is deploying or under analysis.
PausedThe preview is healthy and waits for promotion.
HealthyThe active slot serves the desired revision.
DegradedThe last rollout failed or the active slot is unhealthy.

REST API

MethodPathAuth
GET/healthznone
GET/api/v1/apps, /api/v1/apps/{app}none. Status as JSON.
POST/api/v1/apps/{app}/{sync,promote,abort,rollback,retry}Bearer token
POST/api/v1/apps/{app}/webhookper-app HMAC or token
POST/api/v1/webhookglobal HMAC or token
GET/metricsnone. Prometheus format.
curl -s -X POST -H "Authorization: Bearer $DUOD_TOKEN" \
  http://127.0.0.1:9800/api/v1/apps/shop/promote

Prometheus metrics

Scrape /metrics. Useful series include duod_app_phase, duod_app_synced, duod_app_active_healthy and duod_rollouts_in_flight. Alert on duod_app_active_healthy == 0 and on apps that stay out of sync.
