Write a service's compose file

duod runs the same compose file twice, as the projects <app>-blue and <app>-green. It injects three variables: BG_APP, BG_SLOT (blue or green) and BG_REVISION (the Git commit).

Example

# apps/shop/compose.yaml in the GitOps repo
services:
  web:
    image: ghcr.io/acme/shop:1.8.0          # bump this line to release
    restart: unless-stopped
    deploy:
      replicas: 2                           # = routes[].replicas in duod.yaml
    environment:
      APP_REVISION: ${BG_REVISION}          # echo as X-Revision (healthCheck.revisionHeader)
      APP_SLOT: ${BG_SLOT}
      DATABASE_URL: postgres://shop@db:5432/shop
    healthcheck:
      test: ["CMD", "wget", "-qO-", "http://localhost:3000/health"]
      interval: 5s
      retries: 3
    networks: [default, duod-edge, shared]

  worker:                                   # not routed -> no duod-edge needed
    image: ghcr.io/acme/shop:1.8.0
    command: ["bin/worker"]
    networks: [shared]

networks:
  duod-edge:
    external: true
  shared:
    external: true            # created by the shared-infra project (db, redis)
    name: shop-shared

Full files: examples/deploy-repo.

Rules

  • Join duod-edge. Attach every routed service to the external network duod-edge. Traefik reaches it as <app>-<color>-<service>-<n>:<port>.
  • No ports and no container_name. Both colors run side by side, so fixed ports and names would clash.
  • Match replicas. Set routes[].replicas to the service's deploy.replicas.
  • Add a health endpoint. Expose the path that healthCheck.path probes, and return 200 only when the app is ready.

Stateful services stay outside the slot

Run databases, Redis and queues in a separate Compose project. Both colors use them during the switch, so they must not be duplicated or restarted with a slot.

Database migrations

Keep migrations backward-compatible: expand, then contract. The old color must keep working against the new schema until it is scaled down, and also if you roll back.

Background workers

Workers inside a slot run twice while both colors are up. Make jobs idempotent, or move singleton workers into the shared project.

Release by editing Git

A release is a commit that changes the compose file, usually the image tag. Build images in CI and reference them by tag or digest. duod pulls images during the rollout when source.pull is always.

git commit -am "shop: 1.8.1"
git push
