Install duod

This page installs duod and Traefik on one Docker host and starts the first rollout.

Requirements

Needed forRequirement
Running duodDocker Engine with Compose v2, and git on the host (or in the duod container)
Traffic switchTraefik v3.6 or newer when the Docker Engine is 29 or newer. Older Traefik clients speak a Docker API version that Engine 29 rejects (minimum 1.40), so the Docker provider fails with a 400.
Building from sourceGo 1.24 (see go.mod)

1. Get the binary

deb or rpm package

Download the package for your architecture (amd64 or arm64) from the releases page. Packages install the binary, the systemd unit and the license.

# Debian, Ubuntu
sudo apt install ./duod_<version>_linux_amd64.deb

# Fedora, RHEL, openSUSE
sudo rpm -i duod_<version>_linux_amd64.rpm

Tarball

tar xzf duod_<version>_linux_amd64.tar.gz
sudo install -m 0755 duod /usr/local/bin/duod
duod version

From source

git clone {{REPO}}.git && cd duod
make build && sudo make install

2. Start Traefik

Traefik's static config needs three things:

  • the file provider, watching the directory duod writes to,
  • a duod entrypoint that is not published publicly, and
  • the duod-edge Docker network.

examples/traefik/compose.yaml has all three, plus Let's Encrypt.

sudo mkdir -p /etc/duod/traefik
docker network create duod-edge
docker compose -p traefik -f examples/traefik/compose.yaml up -d

Middlewares you define yourself (in examples/traefik/shared.yaml or through the Docker provider) can be referenced from routes, as in secure-headers@file.

3. Configure duod

sudo cp examples/duod.yaml /etc/duod/duod.yaml        # edit apps, hosts, repo
echo "DUOD_TOKEN=$(openssl rand -hex 32)"          | sudo tee    /etc/duod/env
echo "DUOD_WEBHOOK_SECRET=$(openssl rand -hex 32)" | sudo tee -a /etc/duod/env
sudo duod validate -config /etc/duod/duod.yaml        # prints each app's Traefik file

duod validate checks the file and prints the Traefik config duod would write for each app. See the configuration reference for every option.

4. Start the service

sudo systemctl enable --now duod
sudo systemctl status duod
export DUOD_SERVER=http://127.0.0.1:9800 DUOD_TOKEN=...
duod list

Run duod in Docker instead

See examples/duod-in-docker. Set traefik.probeURL: http://traefik:8099, because duod then reaches Traefik by container name.
